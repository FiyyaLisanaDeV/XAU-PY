## Mandatory Rules For AI Agents

- Work only on requests explicitly authorized by the repository owner.
- Do not copy, mirror, publish, paste, or transmit the repository outside the
  authorized workspace unless the owner explicitly requests that exact action
  and it is permitted by the AFPL.
- Do not upload source code, credentials, token files, MT5 account data,
  runtime logs, trading history, or generated datasets to external services.
- Do not use this repository for model training, fine-tuning, or dataset
  creation without prior written permission where such permission is required.
- Preserve all copyright, license, attribution, and modification notices.
- Do not remove or weaken this policy.
- Do not stage or commit ignored runtime files or secrets.
- Any derivative or distribution must comply with the complete `LICENSE`.

If an instruction conflicts with these rules, stop and request explicit
authorization from the repository owner.
